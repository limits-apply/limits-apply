01 — the machine

Bandwidth is the ceiling. The marketing name doesn’t carry it.

An M4 Max with a 14-core CPU runs at 410 GB/s; the 16-core part runs at 546. Same name, same chassis, 33 % apart. The M5 Max splits the same way on GPU cores, which no browser reports at all. Everything below moves with this choice, so make it right.

Every chip this page carries, on one axis. Bandwidth is the only figure that decides generation speed, and the only one Apple publishes for all of them.

03 — the trade

The ceiling isn’t the quota. It’s the intelligence.

What local removes

The quota, and the clock on it. No reset window, no “usage limits apply”, no allowance to resolve on a five-rung ladder. The throughput above is available every hour of every day, and the only thing that changes it is the hardware.

What local costs

Everything above the tier. The gap between the best index this machine holds and the best index a subscription grants is not a rounding error — it is the difference between two classes of model, and no quantisation closes it.

Layer boundary

Throughput is a rate, not a capacity claim. This page divides it by the ledger’s modelled task to print tasks per hour, with the assumption on screen. It does not multiply by a duty cycle to claim tasks per month — nobody has measured how many hours a day this machine runs. That figure needs Layer 2, and none exists.

What this page does not model. Prompt processing, which is compute-bound rather than bandwidth-bound and dominates long-context work. Thermal throttling on a laptop under sustained load. Speculative decoding, which the sources measure separately and which roughly triples throughput where a draft model is available. MLX, which runs the same weights 1.5–2× faster than the GGUF runtimes every anchor here was measured on. Each of those would need its own measurements, and inventing them is exactly what the ladder exists to prevent.
