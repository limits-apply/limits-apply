# Governance

Limits Apply uses a maintainer-led governance model while the contributor community is small.

## Roles

- **Contributors** propose data, workloads, documentation, code, or review.
- **Maintainers** review and merge changes, manage releases and security reports, and enforce the
  project's methodology and code of conduct.
- **The lead maintainer** resolves decisions that remain blocked after discussion. The current lead
  maintainer is `@uslopia`.

Sustained contributors may become maintainers after demonstrating sound judgement across evidence,
code review, and community conduct. Maintainer changes are recorded in this file through a pull
request.

## Decisions

Routine decisions happen in issues and pull requests. Significant changes to provenance rules,
ranking semantics, accepted evidence, privacy, licensing, or governance require a written proposal
with alternatives and trade-offs. Maintainers seek rough consensus; the lead maintainer decides
when consensus cannot be reached and records the rationale publicly.

No vendor, sponsor, or data provider receives editorial control by funding or supplying data.
Conflicts of interest must be disclosed in the relevant discussion.

## Appeals

A contributor may ask for a decision to be reconsidered with new evidence or by identifying a
process error. Repeating the same argument without new information is not an appeal.
